# Course Library

Curated courses are preferred over random playlists. Links here should point to the institution/original publisher whenever possible.

## Computer science

### S — CS50x: Introduction to Computer Science
- Institution: Harvard University
- Type: OpenCourseWare
- Level: Beginner → intermediate
- Link: https://cs50.harvard.edu/x/
- Why: unusually strong introduction to problem solving, algorithms, memory, data structures, Python, SQL and web fundamentals.
- Do: lectures + problem sets + final project.

### S — MIT 6.006: Introduction to Algorithms
- Institution: MIT OpenCourseWare
- Type: University course
- Level: Intermediate
- Link: https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/
- Prerequisites: programming + discrete math comfort
- Why: canonical algorithmic thinking; do problems, not just lectures.

### S — MIT 6.824 / 6.5840 Distributed Systems
- Institution: MIT
- Level: Advanced
- Link: https://pdos.csail.mit.edu/6.824/
- Prerequisites: systems programming, networking, concurrency
- Why: distributed systems through papers and implementation labs.

### A — The Missing Semester of Your CS Education
- Institution: MIT CSAIL
- Link: https://missing.csail.mit.edu/
- Level: Beginner/intermediate
- Why: shell, tooling, debugging, Git, packaging, code quality and modern engineering workflow.

### S — Nand2Tetris
- Organization: Hebrew University project
- Link: https://www.nand2tetris.org/
- Level: Beginner/intermediate
- Why: build a computer stack from logic gates through software; exceptional for architecture intuition.

## Learning rule

For every course:
1. Predict before lecture.
2. Take sparse notes.
3. Complete exercises without watching solutions first.
4. Build a one-page synthesis.
5. Re-test after 1 week and 1 month.
6. Apply one concept in a project or essay.
