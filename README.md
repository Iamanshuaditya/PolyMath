# PolyMath

A rigorous, evidence-aware, interdisciplinary self-education system for becoming a genuine polymath.

> This repository is being built as a private-university-style curriculum: knowledge map, prerequisite graph, core/extended libraries, primary sources, courses, talks, papers, projects, recall systems, and long-term roadmaps.

## Design principles

- Primary sources before summaries where practical.
- Evidence before authority.
- Courses and textbooks for foundations; papers for frontier/contested claims.
- Explicit epistemic labels: established, probable, contested, speculative, philosophical, historical interpretation, esoteric/metaphysical.
- Cross-disciplinary synthesis rather than isolated trivia.
- Application, writing, retrieval practice, and teaching—not passive consumption.
- Legal/public links only; no pirated copyrighted books.

A full curated release is being assembled in this repository.
