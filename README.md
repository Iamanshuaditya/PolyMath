# PolyMath

**A rigorous, evidence-aware, interdisciplinary self-education system.**

PolyMath is an attempt to build a lifelong intellectual operating system: not a giant list of books, not guru worship, and not passive content consumption. The repository organizes what to study, why it matters, what must come first, which sources are strongest, how claims should be evaluated, and how knowledge should be applied.

## Core principles

- **Primary sources before summaries** when practical.
- **Evidence before authority.** “A billionaire said it” is not an argument.
- **Understanding before memorization.**
- **Models before trivia.**
- **Connections before isolated facts.**
- **Practice before passive consumption.**
- **Skepticism before hero worship.**
- **Original/full sources before recycled clips.**
- **Historical claims get source criticism.**
- **Scientific claims get replication/evidence checks.**
- **Business anecdotes stay anecdotes until stronger evidence exists.**
- **Metaphysical claims are never presented as scientific findings.**

## Resource grading

| Grade | Meaning |
|---|---|
| **S** | Foundational / exceptional |
| **A** | Strong recommendation |
| **B** | Useful supplementary resource |
| **C** | Optional |
| **D** | Weak, questionable, outdated or included mainly for critique |

Source types include `PRIMARY SOURCE`, `ACADEMIC`, `TEXTBOOK`, `PRACTITIONER`, `POPULAR SYNTHESIS`, `BIOGRAPHY`, `LECTURE`, `PODCAST`, `DOCUMENTARY`, `BLOG`, and `REFERENCE`.

Epistemic labels include `ESTABLISHED`, `PROBABLE`, `CONTESTED`, `SPECULATIVE`, `PHILOSOPHICAL`, `HISTORICAL INTERPRETATION`, and `ESOTERIC/METAPHYSICAL`.

## What “learned” means

A topic is not complete because you finished a book. You should be able to:

1. explain it simply without notes,
2. reconstruct the strongest argument,
3. identify the evidence,
4. state important limitations/counterarguments,
5. connect it to other disciplines,
6. apply it to a new case,
7. teach or write about it clearly.

## Repository philosophy

The target is not “I have read hundreds of books.” The target is:

> I can think better, understand people and history, recognize bad reasoning, make better decisions, communicate persuasively, build businesses and technology, understand money and strategy, distinguish evidence from storytelling, form independent judgments, and connect ideas across disciplines.

This repository is designed to keep growing—but **comprehensiveness must never become chaos**.
